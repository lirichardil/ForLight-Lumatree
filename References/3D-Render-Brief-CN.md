## 一、项目概述

Lumatree 是一个木质线性 LED 灯具品牌。产品核心是**同一根木质 LED 灯条**,通过不同安装方式衍生出六款灯具。官网需要通过滚动驱动的动画,展示"一根灯条,六种形态"的模块化概念,以及灯具点亮时的光质表现。

本次委托内容:

1. 六款灯具的 3D 建模
2. 材质与灯光设置
3. 动画镜头制作
4. **渲染输出为编号序列帧图片**

**明确不需要的内容:**

- 不需要实时 3D(three.js / WebGL / glTF)
- 不需要输出视频文件(mp4/mov)
- 不需要网页端开发

> **关于输出格式的说明:** 请在 Blender 输出设置中选择 `PNG` 或 `WebP` 图片序列,**不要选择 `FFmpeg Video`**。动画制作流程完全不变,只是导出为逐帧图片而非影片文件。网页端由滚动位置直接映射到帧序号,因此**不存在帧率概念**,帧数只影响流畅度。

## 五、灯光与渲染要求(**本项目重点**)

灯具本身**既是光源、又是被照物**,这是本项目最关键的技术难点。以下要求请务必在报价与执行中确认。

### 5.1 双光源结构(必须)

单纯使用发光材质会导致路径追踪噪点严重。请采用行业标准做法:

- **可见发光体(Emissive Mesh)** — 供相机拍摄,呈现透镜发光外观
- **隐藏面光源(Area Light)** — 关闭相机可见性,负责实际照亮场景

两者位置、颜色一致。

### 5.2 色温必须物理准确(必须)

- 使用 **Blackbody 黑体辐射节点**,直接输入开尔文数值(如 `2700`)
- **禁止手动调橙色代替色温**

### 5.3 Dim-to-Warm 动画(核心卖点)

将 Blackbody 节点数值从 **1800K 动画到 2700K**,同时联动发光强度由 0 递增至满输出。此动画即为产品「调暗变暖」特性的真实还原,是官网首屏的核心镜头。

### 5.4 IES 配光文件(强烈建议)

若甲方能提供 IES 文件,请通过 **IES Texture 节点**载入,使渲染配光与实际产品完全一致。此项将使成片具备光度学准确性。

### 5.5 背景设置(必须)

- **不可使用纯黑 `#000000` 背景。** 纯黑背景无法承接光线衰减,产品会显得像贴图合成。
- 请使用**大面积哑光深灰背板 + 地面**,反射率 **2%–4%**,粗糙度约 0.7
- 灯光落在背板上形成的**衰减渐变**是本项目要展示的核心视觉,必须清晰可见
- Wash 系列必须有墙面与地面供其「洗」,否则无内容可看

### 5.6 辉光与后期合成(必须)

- 辉光(Glare / Bloom)在**合成阶段**添加,不在渲染阶段
- 使用 Glare 节点(Fog Glow + 少量 Streaks)
- **渲染必须输出 32-bit EXR**,以保留超过 1.0 的高光能量
- ⚠️ 若直接输出 8-bit PNG,高光会被截断,辉光将呈现为模糊白块 —— 这是灯具渲染最常见的失败原因

### 5.7 体积光(可选,建议用于 1–2 个镜头)

- Principled Volume,密度 0.01–0.05
- 用于表现 Pendant 64° 向下光锥
- 密度过高会呈现烟雾感,请克制使用

### 5.8 序列帧渲染设置(必须)

| 设置项 | 要求 |
|---|---|
| 运动模糊 | **必须关闭**(用户以滚动控制时间轴,模糊会呈现为拖影) |
| 相机 | 全程锁定,机位固定 |
| 随机种子 | 固定,确保帧间一致 |
| 采样 | 512–1024 + OpenImageDenoise 降噪 |
| 渲染引擎 | Cycles(英雄镜头)/ Eevee Next(长序列,可大幅节省工时) |

## 六、动画镜头清单

| 编号 | 镜头名称 | 内容 | 帧数 |
|---|---|---|---|
| **S1** | `hero-ignition` 点亮 | 哑光黑场景中灯条水平居中、**熄灭状态**(仅边缘轮廓光可见)→ 从 1800K 微光逐步点亮至 2700K 满输出。**透镜逐颗依次点亮,非同时亮起。** | 90 |
| **S2** | `lens-detail` 透镜细节 | 旋转至正面,展示深凹透镜结构与低眩光特性 | 60 |
| **S3** | `hero-transform` 形态转换 | 灯条连续变形:水平 → 竖直变为 Floor Wash → 回到水平、下降立杆变为 Table Task → 顶部垂下吊线变为 Pendant → 依次演绎六款形态。**机位锁定、背景恒定、连续变形不可跳切。** | 180 |
| **S4** | `finish-switch` 饰面切换(可选) | 同机位、同灯光下橡木 / 胡桃木 / 黑蜡木三种饰面 | 3 × 30 |

> **S1 关键要求:** 熄灭状态与点亮状态**必须来自同一个渲染场景**,仅改变发光强度。若分别建立两个场景,点亮过程会呈现为跳切而非调光过程,而调光过程正是本镜头的全部意义。

### 附加静帧(建议同场次完成)

在场景与灯光已搭建完成的情况下,以下内容增量成本极低:

- 六款产品单品静帧,宽度 2400px
- 三种木饰面变体(同机位同灯光,供网页交叉淡入切换)
- 2–3 张 4K 大图,用于网站通栏区块
